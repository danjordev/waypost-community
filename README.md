# Waypost — Your Fallbrook Welcome Guide

A free, personalized "Welcome to Town" guide for military spouses who have just relocated to Fallbrook, California (near Camp Pendleton).

## What it does

A visitor answers a short 5-step questionnaire about their family and interests — kids' ages, whether they're looking for schools, youth sports leagues, churches, co-working spots, dining options, military discounts, and upcoming events. Based on their answers, they receive a custom guide that surfaces only the recommendations relevant to them.

## How to run it

No installation required. Just open `index.html` in any web browser — double-click the file in Finder or File Explorer and it opens directly.

## Project structure

```
waypost/
├── index.html   # Questionnaire + guide (single-page app)
├── styles.css   # Design system — olive, sand, terracotta palette
└── app.js       # Questionnaire logic and guide generator
```

## Guide sections (shown conditionally based on answers)

- Schools & enrollment (FUESD and FUHSD districts)
- Youth sports leagues (AYSO, Little League, basketball, wrestling)
- Faith community (local churches across denominations)
- Neighborhoods & housing (with Camp Pendleton commute notes)
- Remote work & co-working spots
- Local groups, spouse clubs, and newcomer meetups
- Family-friendly restaurants
- Date night spots
- Military discounts at local businesses
- Upcoming Fallbrook events & festivals
- New resident checklist (DMV, utilities, Tricare, voter registration)
